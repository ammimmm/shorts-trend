## 리뷰하는 회사원 (구독 61.8만)
- 쇼츠 길이 중앙값 48초 (30~60초가 대부분), 하루 1개 업로드, 조회 중앙값 55만
- 회사원 캐릭터가 사무실·일상에서 신기한 제품/음식을 직접 써보고 실험함 (비교 실험, "진짜 될까?")
- 의외의 결과·리액션·상황극 유머 (부장님, 직장 상사, 사무실에서 ~하기)
- 제목: 짧은 호기심 유발형 — "~라고?", "~vs~", "필수템", "비싼게 좋을까", "~하면 일어나는 일"
- 히트작: 모기 물렸을 때 필수템(1246만), 선크림 비교 실험(552만), 범죄자가 만든 비누(417만), 맥주패딩(294만)

## 소개팁 IntroTip (구독 73.7만)

- "이 좋은 걸 나만 몰랐네" 톤, 아이디어템·가성비 음식·생활용품을 직접 써보고 소개
- 제목: 정보+반전 — "~의 비밀", "의외로 ~", "오히려 좋아", "굳이 ~", "명불허전 일본 아이디어템"
- 히트작: 내 돈 주고 굳이 안사는 것들(1507만), 명불허전 일본 아이디어템(1121만), 사고를 막아준 아이디어템(1067만), 자동냄비 롤팬 1년 써봄(924만)

## 공통점 = 우리가 찾는 영상
1. 실제 사람이 실물 제품을 손에 들고 직접 사용·테스트한다
2. 결과에 반전/리액션/유머가 있어 끝까지 보게 만든다 (시청 지속)
3. 시청자가 "이거 어디서 사?"라고 묻게 되는 구매 가능한 제품이다
4. 30~60초

## 제외
- AI 생성·CGI 영상, 사진 슬라이드, 남의 영상 짜깁기 모음
- 제품이 없는 영상 (순수 요리, 몰래카메라, 춤 등), 사용 장면 없는 광고/언박싱

## 스토리텔링 (리뷰하는 회사원 조회수 상위 40개 제목 분석, 2026-10-29)
제품을 소개만 하고 끝내지 않고, 짧은 '이야기'로 감싼다. (영상 화면은 직접 못 보고 제목·설명으로 추론한 패턴)
1. 어울리지 않는 무대·캐릭터: 회사원이 '회사에서' 리뷰한다는 설정 자체가 이야기. 부장님·직장 상사·신입사원 등장
   - 예: 부장님 집에서 고기구워먹기(250만), 직장 상사 차에서 밥먹기(198만), 신입사원을 소개합니다(388만, 고양이를 신입사원으로)
2. 기대 → 반전: 광고만 믿고 샀는데 결과가 다름
   - 예: 모든걸 다 따버리는 열쇠 (인줄 알고 산거)(180만)
3. 질문 → 직접 검증: 제목이 질문, 영상이 답
   - 예: 솔잎으로 사이다를 만들 수 있다고?(259만), 텀블러 비싼게 좋을까?(174만), 펩시 vs 코카콜라(146만), 선크림 비교 실험(552만)
4. 제품의 출신·뒷이야기를 훅으로
   - 예: 범죄자가 만든 비누(417만), 일본에서 온 밥도둑(588만), 7억명의 사람들이 먹는 제티 같은거(189만)
5. 생활 속 문제 → 해결
   - 예: 모기 물렸을 때 필수템(1246만), 직장인 필수템 맥주패딩(294만)
6. 시리즈·연재: 같은 캐릭터로 이어지는 이야기
   - 예: 개미 키우기 1~9탄, 고양이 액체설 2

좋은 스토리 흐름: 상황 설정(누가·어디서) → 기대/의문 → 직접 써보기·실험 → 반전/결과 → 한 줄 마무리(다음 편 예고)
