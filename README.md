# 쇼츠 트렌드 레이더

해외 YouTube Shorts에서 **뜨고 있는 제품 영상을 하루 10번 자동으로 수집**해서 내 홈페이지에 보여줍니다.
처음에 한 번만 설정하면 됩니다. 이후에는 홈페이지에 들어가서 보기만 하면 됩니다.

- 수집: GitHub Actions가 하루 10번 자동 실행 (무료)
- 홈페이지: GitHub Pages, 주소는 `https://내아이디.github.io/shorts-trend/` (무료)
- 서버, 비용, 터미널 명령어가 모두 필요 없습니다.

---

## 처음 한 번만 하는 설정 (약 15분)

### 1단계. YouTube API 키 발급
1. https://console.cloud.google.com 에 구글 계정으로 로그인합니다.
2. 상단의 **프로젝트 선택**에서 **새 프로젝트**를 만듭니다. 이름은 아무거나 괜찮습니다.
3. **API 및 서비스**, 이어서 **라이브러리**로 갑니다. `YouTube Data API v3`를 검색해서 **사용**을 누릅니다.
4. **API 및 서비스**, 이어서 **사용자 인증 정보**로 갑니다. **+ 사용자 인증 정보 만들기**에서 **API 키**를 고르면 키가 생깁니다. 이 키를 복사해 둡니다.

### 2단계. 저장소에 API 키 등록 (비밀값이라 외부에 노출되지 않음)
1. GitHub 저장소 페이지에서 **Settings**, **Secrets and variables**, **Actions** 순서로 들어갑니다.
2. **New repository secret**을 누릅니다.
   - Name: `YOUTUBE_API_KEY`
   - Secret: 1단계에서 복사한 키
3. **Add secret**을 누릅니다.

### 3단계. 홈페이지 켜기
1. 저장소에서 **Settings**, 이어서 **Pages**로 들어갑니다.
2. Source는 `Deploy from a branch`, Branch는 `main`에 폴더 `/docs`로 정하고 **Save**를 누릅니다.
3. 1~2분 뒤 위쪽에 홈페이지 주소가 표시됩니다. 휴대폰 홈 화면에 추가해 두면 편합니다.

### 4단계. 첫 수집 실행
1. 저장소에서 **Actions** 탭, 왼쪽의 **쇼츠 트렌드 수집**을 차례로 누릅니다.
2. **Run workflow**, 이어서 초록색 **Run workflow** 버튼을 누릅니다.
3. 2~3분 뒤 홈페이지를 새로고침하면 결과가 보입니다.

이후에는 하루 10번(한국시간 약 2~3시간 간격) 자동으로 수집되고 홈페이지가 갱신됩니다.

---

## 홈페이지 보는 법

**회차별 결과** 탭은 한 번 수집할 때마다 나온 순위입니다. 위의 드롭다운에서 과거 회차를 고를 수 있습니다.

**반복 등장 (누적)** 탭은 여러 회차를 합친 결과입니다. **이 탭에서 제품을 고르는 걸 추천합니다.**
- 반복 등장이 많으면 반짝 인기가 아니라 꾸준히 뜨는 영상입니다.
- 증가 조회는 처음 잡힌 뒤 실제로 늘어난 조회수라서 지금 성장 중인지 알 수 있습니다.

| 지표 | 의미 |
|---|---|
| 종합점수 | 시간당 조회 40% + 아웃라이어 35% + 구매의도 25% (0~100) |
| 시간당 조회 | 업로드 후 시간당 평균 조회수 |
| 아웃라이어 | 조회수 ÷ 구독자. 5배 이상이면 제품 힘으로 터진 영상 |
| 구매의도 | "where to buy", "link", "need this" 같은 댓글 수 |

## 설정 바꾸기 (GitHub 웹에서 파일을 열고 연필 아이콘으로 수정)

- **검색 키워드**: `keywords.txt`에 한 줄에 하나씩 적습니다. 키워드 하나에 할당량 100유닛이 듭니다.
- **수집 국가나 기간**: `.github/workflows/collect.yml`의 `python trend_finder.py --json-dir docs/data` 줄 끝에 옵션을 붙입니다.
  - 예: `--region GB --days 3` (영국, 최근 3일)
- **수집 시간**: 같은 파일의 `cron` 줄을 고칩니다(UTC 기준, 한국시간에서 9시간을 뺀 값).

## 주의사항
- **무료 할당량은 하루 10,000유닛**이고, 기본 설정으로 1회에 약 850유닛 × 10회 = 약 8,500유닛을 씁니다. 키워드를 늘리면 하루 실행 횟수를 줄여야 합니다(cron에서 시간을 빼면 됩니다).
- 무료 GitHub Pages는 **공개 저장소**에서만 동작합니다. 따라서 홈페이지 주소를 아는 사람은 결과를 볼 수 있습니다. API 키는 Secret이라 공개되지 않습니다.
- 결과는 최근 70회(약 1주일)만 보관하고, 오래된 것은 자동으로 삭제합니다.
- 수집이 멈춘 것 같으면 Actions 탭에서 실패(빨간 X)가 있는지 확인하세요. 실패한 항목을 누르면 원인이 나옵니다.

## (선택) 내 PC에서 엑셀로 받기
`.env.example`을 `.env`로 복사해 키를 넣은 뒤 아래 두 명령을 실행하면 `output/` 폴더에 엑셀이 생깁니다.

```bash
pip install -r requirements.txt
```

```bash
python trend_finder.py
```
