# 내 쇼츠 스튜디오: 직원 관리

홈페이지: **https://ammimmm.github.io/shorts-trend/**

GitHub Actions에서 자동으로 일하는 "직원"들을 홈페이지에서 관리합니다. 서버도 비용도 필요 없습니다.

| 직원 | 하는 일 | 근무 |
|---|---|---|
| 🎬 헌터 | 서양권에서 터진 '제품 써보기' 쇼츠를 찾음. AI 영상과 비서양권 영상은 제외하고, 리뷰하는회사원·소개팁 스타일과 비슷한 순으로 보고 | 하루 7회 |
| 🛒 스카우터 | 사서 써보는 쇼츠를 찍었을 때 호기심을 끌 제품을 **아마존·테무로 나눠** 보고. 쇼츠 제목, 촬영 아이디어, 예상 반응을 함께 정리 | 하루 2회 + 더 찾아줘 |

- 판단(AI 영상 여부, 스타일 일치도, 제품명, 추천 이유)은 **GitHub Models 무료 AI**가 합니다. AI가 안 되면 규칙 기반으로 계속 일합니다.
- 기준 스타일 분석: `staff/config/reference_style.md`

## 일 시키기
- 자동: 정해진 시간마다 알아서 근무합니다.
- 수동: 홈페이지 직원 카드의 **지금 일 시키기**를 누릅니다.
- **⚙️ GitHub 연결**(한 번만): 홈페이지 오른쪽 위에서 토큰을 넣어 두면 버튼 한 번으로 바로 일을 시킵니다. 보고서가 올라오면 자동으로 새로고침되고, **더 찾아줘**와 **담기**도 이 연결로 동작합니다. 토큰은 그 기기 브라우저에만 저장됩니다.

## 스카우터가 제품을 찾는 두 가지 길
1. **자동 발굴**: YouTube에서 아마존·테무 제품 시연·하울·리뷰 영상(쇼츠 제외)을 찾아, 제목·설명·챕터에 나온 제품을 AI가 뽑고 평가합니다. 근무할 때마다 다른 검색어를 씁니다.
2. **직접 담기**: 아마존·테무 상품 페이지에서 설명 영상을 보다가 신기하면 담습니다.
   - PC: 스카우터 보고서 아래의 **🛒 스카우터에 담기** 버튼을 북마크바로 끌어다 두고, 상품 페이지에서 누릅니다.
   - 휴대폰: 상품 주소를 복사해서 **➕ 담기**에 붙여넣습니다.
   - 메모에 "영상에서 뭐가 신기했는지"를 적으면 AI가 가장 중요하게 참고합니다.

보고서 화면에서는 **안 본 제품만 10개씩** 보여줍니다. 새로고침이나 **더 보기**를 누르면 다음 제품이 나오고, 다 보면 **더 찾아줘**로 추가 근무를 시키면 됩니다. 마음에 드는 제품은 **☆ 찜**으로 모아 둘 수 있습니다.

## 설정 바꾸기 (GitHub 웹에서 파일을 열고 연필 아이콘으로 수정)
| 바꿀 것 | 파일 |
|---|---|
| 헌터 검색 키워드 (1개당 할당량 100, 8개가 적정) | `staff/config/hunter_keywords.txt` |
| AI가 참고하는 기준 스타일 | `staff/config/reference_style.md` |
| 근무 시간 | `.github/workflows/video-hunter.yml`, `product-scout.yml`의 `cron` (UTC 기준 = 한국시간 - 9) |
| 홈페이지의 직원 이름과 설명, 채용 예정 목록 | `docs/data/staff.json` |

## 구조 (직원을 늘릴 때)
```
staff/common.py          직원 공용 도구 (YouTube, 무료 AI, 보고서 저장)
staff/video_hunter.py    직원1 헌터
staff/product_scout.py   직원2 스카우터
.github/workflows/       직원별 근무 일정
docs/index.html          직원 관리 홈페이지
docs/data/staff.json     직원 명단
docs/data/<직원id>/      직원별 상태(status.json), 근무 일지(index.json), 보고서(runs/)
```
새 직원은 `staff/새직원.py`, `.github/workflows/새직원.yml`, `staff.json` 항목을 추가하면 됩니다.

## 알아둘 점
- YouTube 무료 할당량은 하루 10,000입니다. 헌터는 하루 약 6,100을 쓰고, 스카우터는 1회에 약 400(사이트 하나만이면 약 200)을 씁니다. **더 찾아줘는 하루 7~8회 정도**까지 여유가 있습니다.
- 다른 사람 영상의 **시청 지속시간**은 YouTube가 공개하지 않습니다. 그래서 좋아요율, 구매의도 댓글, 아웃라이어로 추정합니다.
- 영상 화면은 직접 볼 수 없습니다. AI는 제목, 설명, 태그, 댓글로 판단합니다.
- 아마존·테무 페이지를 서버가 자동으로 읽는 것은 두 사이트의 약관상 금지라서 하지 않습니다. 대신 YouTube 영상과 직접 담기를 씁니다.
- 일부 사이트는 보안 설정 때문에 북마크 버튼이 동작하지 않을 수 있습니다. 그때는 **➕ 담기**에 주소를 붙여넣으세요.
